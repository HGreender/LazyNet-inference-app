# LazyNet Inference App

Десктопное приложение (PyQt6) для пакетного инференса сегментационных моделей **LazyNet**:
загружает веса, прогоняет папку изображений через модель и сохраняет маски, оверлеи
и наглядные конкатенации — с живым логом, предпросмотром результатов и тёмным интерфейсом.

## Возможности

- **Выбор архитектуры модели** — 4 варианта:
  `efficientnetb4_unet`, `efficientnetb4_unet_1ch`, `efficientnetb4_unet++`, `efficientnetb4_unet++_1ch`
- **Выбор функции аугментации** (из `fast_ml_tools.ml.augmentations`):
  - `get_manga_panel_bubble_augmentation` (по умолчанию)
  - `get_grayscale_imagenet_augmentation`
  - `get_imagenet_encoder_augmentation`
  - `get_lungs_imagenet_encoder_augmentation`

  При несовпадении числа входных каналов аугментации и модели приложение
  автоматически переключается на совместимую аугментацию (с предупреждением в логе).
- **Параметры инференса**: порог бинаризации, цвет и сила оверлея, размер батча,
  число воркеров DataLoader и пула сохранения.
- **Гибкое сохранение**: маски (`*_mask.png`), оверлеи (`*_overlay`),
  конкатенации «оригинал + маска + оверлей» (`*_viz`) — каждый тип включается отдельно.
- **Предпросмотр** — первый обработанный кадр появляется в правой панели в реальном времени.
- **Фоновые потоки** — инференс и проверка обновлений выполняются в `QThread`, UI не зависает.
- **Обновление приложения из git** — кнопка в шапке проверяет новые коммиты ветки `main`
  и подтягивает их (fast-forward), после чего предлагает перезапуск.
- **Тёмная тема** — вся палитра и стили вынесены в `ui/theme.py`.

## Требования

- **Python 3.10+** (проверено на 3.14)
- **Git** (для функции обновления приложения)
- GPU с CUDA — рекомендуется (при инференсе используется `torch.cuda`,
  при отсутствии GPU автоматически используется CPU)
- Linux: glibc 2.28+ (требование PyQt6)

## Установка

### 1. Клонируйте репозиторий

```bash
git clone git@github.com:HGreender/LazyNet-inference-app.git
cd LazyNet-inference-app
```

### 2. Создайте виртуальное окружение

```bash
python3 -m venv venv
source venv/bin/activate        # Linux/macOS
# python -m venv venv
# venv\Scripts\activate         # Windows
```

### 3. Установите кастомную библиотеку `fast-ml-tools` ⚠️

Приложение использует **собственную библиотеку** [`fast-ml-tools`](https://github.com/HGreender/LazyNet-fast-ML-tools)
(класс `LazyNet` и функции аугментаций). Она **не публикуется на PyPI**,
поэтому её нужно установить напрямую из GitHub:

```bash
pip install git+https://github.com/HGreender/LazyNet-fast-ML-tools.git@dev
```

> Имя пакета — `fast-ml-tools`, импортируется как `fast_ml_tools`.
> Если обновляете библиотеку, переустановите с принудительной заменой:
> `pip install --force-reinstall git+https://github.com/HGreender/LazyNet-fast-ML-tools.git`

>**Обязательно использование ветки dev** ***(временно)***

### 4. Установите PyTorch (под вашу версию CUDA)

```bash
# CUDA 12.x (пример)
pip install torch --index-url https://download.pytorch.org/whl/cu126
# CPU-only
pip install torch --index-url https://download.pytorch.org/whl/cpu
```

> Версию CUDA-сборки torch подберите под свой драйвер: `nvidia-smi` покажет актуальный CUDA.

### 5. Установите остальные зависимости

```bash
pip install -r lazy_net_inference_app/requirements.txt
```

Состав `requirements.txt`:

| Пакет | Назначение |
|---|---|
| `PyQt6>=6.4.0` | GUI |
| `torch>=2.0.0` | инференс (устанавливается отдельно, см. шаг 4) |
| `numpy>=1.24.0` | обработка массивов |
| `opencv-python>=4.8.0` | чтение/сохранение изображений, оверлеи |
| `fast-ml-tools>=0.1.0` | кастомная библиотека (устанавливается из GitHub, см. шаг 3) |
| `albumentations>=1.3.0` | аугментации |
| `tqdm>=4.65.0` | прогресс |
| `loguru>=0.7.0` | логирование |

## Запуск

```bash
cd lazy_net_inference_app
python main.py
```

Или через готовый скрипт (Linux):

```bash
cd lazy_net_inference_app
./run_linux.sh
```

Скрипт задаёт `QT_QPA_PLATFORMTHEME=generic`, чтобы диалоги выбора файлов
корректно отображались в тёмной теме.

## Использование

1. **Модель**
   - выберите архитектуру в выпадающем списке;
   - укажите путь к файлу весов `*.pth` (кнопка `...`);
   - выберите функцию аугментации (совместимость с числом каналов проверяется автоматически).
2. **Пути**
   - **Входная папка** — изображения `.png, .jpg, .jpeg, .bmp, .tif`;
   - **Выходная папка** — создаётся автоматически.
3. **Параметры**
   - **Порог** (0–1) — бинаризация карты вероятностей;
   - **Цвет оверлея** и **Сила оверлея** (0–1);
   - **Batch size**, **Workers** (DataLoader), **Save workers** (поток сохранения);
   - флаги: **Сохранять маски**, **Сохранять конкат**, **Сохранять оверлей**.
4. Нажмите **▶ Запустить** — в логе появится ход процесса, в правой панели —
   предпросмотр первого кадра, в статус-баре — процент.
   Кнопка **⏹ Остановить** прерывает инференс (уже обработанные кадры сохраняются).

Все параметры автоматически сохраняются в `config.json` в корне проекта
и подхватываются при следующем запуске.

## Выходные файлы

Результаты складываются в подпапки выходной директории:

```
<output_dir>/
├── masks/    <имя>_mask.png      # бинарная маска (0/255)
├── overlays/ <имя>_overlay.<ext> # оригинал с цветным оверлеем
└── concat/   <имя>_viz.<ext>     # [оригинал | маска | оверлей] в ряд
```

## Конфигурация (`config.json`)

| Ключ | По умолчанию | Описание |
|---|---|---|
| `model_path` | `""` | путь к весам `*.pth` |
| `input_dir` | `""` | папка с изображениями |
| `output_dir` | `""` | папка для результатов |
| `model_name` | `efficientnetb4_unet++_1ch` | архитектура модели |
| `augmentation_fn` | `get_manga_panel_bubble_augmentation` | функция аугментации |
| `threshold` | `0.5` | порог бинаризации |
| `overlay_color` | `[0, 255, 0]` | цвет оверлея RGB |
| `overlay_strength` | `0.5` | прозрачность оверлея |
| `batch_size` | `50` | размер батча |
| `num_workers` | `2` | воркеры DataLoader |
| `save_workers` | `4` | пул потоков для сохранения |
| `save_masks` | `true` | сохранять бинарные маски |
| `save_concat` | `false` | сохранять конкатенации |
| `save_overlay` | `true` | сохранять оверлеи |

Файл создаётся и обновляется приложением автоматически — править его вручную не нужно.

## Обновление приложения

Кнопка **⟳ Проверить обновления** в шапке (рядом с чипом версии):

1. `git fetch origin main` — подтягивает информацию о новых коммитах;
2. `git rev-list HEAD..origin/main --count` — считает, сколько коммитов «впереди»;
3. если новых коммитов нет — «Приложение актуально»;
4. если есть и рабочее дерево **чистое** — `git merge --ff-only origin/main`;
5. после обновления — диалог «Перезапустить приложение сейчас?»:
   при подтверждении запускается новый процесс (`QProcess.startDetached`)
   и текущее окно закрывается.

Ограничения (ошибки выводятся в лог и диалог, приложение не падает):

- **грязное рабочее дерево** — merge не выполняется, нужно закоммитить или `git stash`;
- **нет remote `origin` / нет ветки `main`** — понятное сообщение об ошибке;
- **расхождение веток** (локальные коммиты, которых нет на удалёнке) — fast-forward невозможен,
  ошибка сообщается, ничего не перезаписывается;
- **нет сети / SSH-ключей** — ошибка `git fetch` выводится как есть.

Чип версии в шапке после успешного обновления показывает хэш текущего коммита: `v1.0 · <hash>`.

## Частые проблемы

| Проблема | Решение |
|---|---|
| `ImportError: fast_ml_tools` | библиотека не установлена — см. шаг 3 установки (установка из GitHub, не с PyPI) |
| `ImportError: libglib-2.0.so.0` / ошибки PyQt6 | старый glibc (< 2.28) — обновите систему или используйте новое окружение |
| `CUDA out of memory` | уменьшите `Batch size` и/или `Workers` |
| «Ожидался файл .pth» | укажите путь именно к файлу весов `.pth`, а не к папке |
| Обновление не выполняется | проверьте `git status` (должно быть чисто) и доступ к remote: `git remote -v` |
| Оверлей «плывёт» по размеру | не должно происходить: маска ресайзится до оригинальных размеров кадра; если видите артефакты — проверьте, что входные изображения не повёрнуты на 90° (EXIF) |
